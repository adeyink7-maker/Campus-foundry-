# Campus Foundry

A social and marketplace hub for university students: feeds, student marketplace, faculty/department hubs, direct messages, snaps and profile cards, all in one app.

🔗 **Live app:** https://campus-foundry.vercel.app

## Features
- Campus feed and snaps (stories)
- Student marketplace with traders, orders and chat
- Hubs for faculties, departments, clubs and news pages
- Direct messaging with message requests
- Student verification and profile "player cards"
- Global search and discovery

## Tech stack
React · TypeScript · Vite · Supabase (auth, database, storage) · Vercel · PWA

## Run locally
1. `bun install`
2. Copy `.env.example` to `.env` and add your Supabase URL and anon key
3. Run the SQL files in `/migrations` in your Supabase SQL editor
4. `bun run dev`
